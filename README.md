## 🌟 Featured Projects

### 🪶 [The-Sanskrit-Parser (Sakhaa)](https://github.com/samvadah/The-Sanskrit-Parser)
A high-performance, unified Sanskrit NLP parser built for:
- **Padaccheda** (Word segmentation) & Morphological analysis
- Sanskrit **Lexicon lookup & Akshara breakdown**
- Multi-script transliteration and machine translation integration

---

### 🔗 [Sandhify (सन्धीराट्)](https://github.com/samvadah/sandhi)
A deterministic, rule-based Pāṇinian Sanskrit *Sandhi* engine that applies classical **Aṣṭādhyāyī sūtras** to:
- Generate fully joined, sandhified sentences and compounds
- Provide boundary-level summary tables
- Deliver transparent, step-by-step sūtra derivations

---

### ⚖️ [Satyaasatyam](https://github.com/samvadah/satyaasatyam)
An interactive 4-player social deduction game of truth and untruth (*Satya vs. Asatya*):
- Based on classical themes and logic
- Dual language support in **Sanskrit & English**
- Built interactively using **Python & Streamlit**
